# JSON-шаблон: Генерация тест-кейсов

## Назначение
На основе описания функции и её кода предложить тест-кейсы.

## Промт
Вы — сеньор-разработчик/QA-инженер. Ваша задача — на основе описания функции и её кода предложить тест-кейсы.

Язык: <<ЯЗЫК_ПРОГРАММИРОВАНИЯ>>
Фреймворк тестирования: <<ФРЕЙМВОРК_ТЕСТОВ>>
Назначение функции: <<КРАТКОЕ_ОПИСАНИЕ_ФУНКЦИИ>>
Код функции: <<КОД_ФУНКЦИИ>>

Требования:
1. Сформировать список тест-кейсов: нормальные случаи, граничные случаи, некорректные входные данные.
2. Для каждого кейса указать: описание, входные данные, ожидаемый результат.
3. Сгенерировать пример кода тестов под указанный фреймворк.
4. Строго вернуть результат в JSON.

## Формат ответа
{
  "test_cases": [
    {
      "id": "case_1",
      "type": "normal | edge | invalid",
      "description": "Что проверяем",
      "input": "Описание входных данных или структура",
      "expected_output": "Ожидаемый результат"
    }
  ],
  "test_code_example": "Пример кода с тестами"
}
